# Template And Layout Selection

## Select A Or B

Choose **Field Notes A** for reflective education, creator workflows, psychology, personal knowledge, natural metaphors, and warm editorial narration. It uses deep green, botanical line art, serif display type, and a warm secondary accent.

Choose **Dark Teal Intelligence** for market analysis, finance, product strategy, evidence reviews, research, metrics, business comparisons, and institutional narration. It uses charcoal/teal report surfaces, rounded display type, evidence rules, and structured geometry.

Do not mix A and B inside one deck.

## Field Notes A Layouts

| Type | Use |
|---|---|
| `cover` | Opening title and one supporting statement |
| `question` | One question with two interpretations |
| `core-idea` | One concept plus a simple visual metaphor |
| `capability-grid` | Exactly three parallel capabilities |
| `platform-list` | Up to six named platforms or categories |
| `data-fields` | Several fields or data types with one conclusion |
| `process` | Exactly three ordered steps |
| `caution` | Risks, prohibitions, or ethical boundary |
| `support` | One lead statement plus three supporting points |
| `closing` | Short closing or call to action |
| `single-card` | One core concept needing a full visual surface |
| `dual-compare` | A versus B comparison |
| `stacked-compare` | Not X, but Y; reversal or progression |
| `quote-card` | One memorable conclusion or quote |
| `quad-card-grid` | Exactly four parallel items |
| `six-card-grid` | Exactly six short parallel items |
| `split-vertical-list` | Left claim plus exactly three right-side items |
| `hierarchy-stack` | Exactly three semantic levels |
| `tool-list` | Exactly three named tools or products |
| `large-explainer` | One chapter statement plus substantial explanation |

## Dark Teal Intelligence Layout Families

- `hero`: opening, section statement, dual signal, or statement with one real visual.
- `editorial`: claim plus evidence, quote, stack, or memorable mark.
- `split-proof`: text and one real evidence object, image left or right.
- `portrait`: one featured subject and supporting facts.
- `values-grid`: two, three, or four peer value statements; exactly four peer items use `four-up`.
- `timeline`: genuinely ordered or causal stages with rising or flat progression; never an unordered four-item list.
- `revenue-arc`: increasing or decreasing quantitative trajectory.
- `metric`: two, three, five, sequence-four, or evidence-hero metrics.
- `audience`: wide or compact audience segmentation.
- `map`: geographic or spatial evidence, map left or right.
- `roadmap`: three-step sequence or four overlapping stages.
- `compare/capability-boundary`: one capability and its explicit boundary.

Read the selected template's `design.md` for exact capacity and geometry. If no approved layout fits, split the narration. Do not invent a new family inside an article job.
