# Dark Teal Intelligence

Dark Teal Intelligence is a restrained editorial intelligence system for research, market analysis, strategy, evidence, comparisons, and metrics. It uses report geometry, thin evidence rules, rounded display typography, clear body copy, and large information-bearing shapes.

## Layout purposes

- `hero--center`, `hero--lower-left`: short opening, reveal, or closing.
- `hero--split-visual`: statement plus one real visual.
- `hero--dual-signal`: opening with two concrete signals.
- `editorial--balanced`: narrative and evidence with similar weight.
- `editorial--evidence-wide`: one dominant proof block.
- `editorial--statement-mark`: judgment with an oversized subject mark.
- `editorial--evidence-stack`: evidence rows leading to one judgment.
- `split-proof--image-left`, `split-proof--image-right`: one real image paired with a judgment.
- `portrait--balanced`, `portrait--featured-left`: two real people with equal or primary/secondary emphasis.
- `values-grid--two-up-wide`, `values-grid--three-up`, `values-grid--four-up`: parallel concepts.
- `timeline--rising`, `timeline--flat`: ordered milestones.
- `revenue-arc--rising`, `revenue-arc--descending`: directional quantitative change.
- `metric--two-up`, `metric--three-up`, `metric--five-up`: measured values.
- `metric--sequence-four`: four ordered indicators.
- `metric--evidence-hero`: one dominant evidence metric.
- `compare--capability-boundary`: two capability or boundary sides.
- `audience--wide`, `audience--compact`: related audience groups.
- `map--map-left`, `map--map-right`: real geographic evidence.
- `roadmap--overlap-four`, `roadmap--sequence-three`: related responsibilities or ordered stages.

## Visual character

Use one controlled theme preset for the entire deck. `intelligence-teal` uses charcoal and teal; `graphite-amber` uses warm graphite and amber. Preserve the report hierarchy, evidence grammar, rounded display typography, and Dark Teal font identity regardless of preset.

Use the preset's semantic tones to clarify evidence hierarchy: a key title phrase, narrative turn, comparison side, or core conclusion can carry an accent when the distinction is meaningful. Some pages may need no color contrast, but the deck should not become uniformly single-tone when the narration contains real hierarchy. Avoid fixed color pairs, mandatory two-color pages, and decorative rainbow emphasis.

Use metric layouts only for measured values, sequence layouts only for ordered content, and visual layouts only when the authorized real asset exists. The real mother structure, fonts, theme presets, fillable fields, and asset positions live only in `template.html`.
